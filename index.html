    3 · Sound rules

    A rule has two sides: Value (find) = which blocks to match (not written to the filter); Sound (plays) = what those blocks will play. Category rules target type/tier/bucket; item rules target a baseType or an items (group). A type rule can be narrowed by an optional tier (e.g. gold + stack3 = gold over 3000). Item rules have an optional conditions box (e.g. Rarity Unique, StackSize >= 1000) that builds a fresh block. ▶ plays a sound (if you uploaded it), ✎ types a custom name, 🔍 shows the items a rule affects.
